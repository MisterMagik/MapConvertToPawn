# MapConverterToPawn
A tool to convert maps from the Map Editor to Pawn code for use in SA-MP (San Andreas Multiplayer). This tool allows you to take your custom maps created in the Map Editor and generate the necessary Pawn code to implement them in your SA-MP server.

# Features
Convert RemoveBuilding function to Pawn code.
Convert object function to Pawn code. 

# Usage
1. Open the Map Editor and create your custom map.
1. Once you have finished creating your map, save it and export it as a .map file.
1. Run the MapConverterToPawn tool and select your .map file.
1. The tool will process the .map file and generate the corresponding Pawn code for the RemoveBuilding function.
1. Copy the generated Pawn code and paste it into your SA-MP server script where you want to remove the building.
1. Compile your SA-MP server script and test it to see the changes in your custom map.

# Note
- Make sure to have the necessary permissions and rights to use the Map Editor and SA-MP server.
- Always backup your server scripts before making any changes to avoid potential issues.
- The generated Pawn code may require additional adjustments based on your specific server setup and requirements.
- This tool is intended for use by developers and server administrators who are familiar with SA-MP scripting and the Map Editor.
